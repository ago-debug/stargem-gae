# 📎 _CLAUDE/05_allegati/

Cartella per allegati che Gaetano carica per Claude (Cowork) da consultare:
Excel, PDF, screenshot, esportazioni Drive, immagini, ecc.

## Regole

- Nominare i file in modo descrittivo (es. `team_TURNI_2526.xlsx`).
- NON mettere timestamp nel nome dei file vivi (regola 2 del 00_LEGGIMI globale).
- Quando un allegato è obsoleto: spostare in `99_archivio/` con prefisso `YYYY_MM_DD_HHMM_`.
- Antigravity può leggere ma non scrive qui (territorio Claude).

## Tipi supportati per la lettura diretta da Claude

`.xlsx` `.csv` `.tsv` `.pdf` `.png` `.jpg` `.docx` `.md` `.txt` `.json`
